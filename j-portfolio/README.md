# Jeyavarshini J. Portfolio

Premium editorial-style single-page portfolio built with React 19, TypeScript, Vite, Tailwind CSS, and a small shadcn/ui-inspired Button component.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Publish for free with GitHub Pages

1. Create a public GitHub repository named `<your-github-username>.github.io`.
2. Upload the contents of this project.
3. Run `npm install` and `npm run build`.
4. Publish the generated `dist` folder using GitHub Pages, or connect the repository to a static hosting provider.
5. For a simple repository-hosted deployment, GitHub Actions can be used to build `dist` and publish it to Pages.
